# 🚀 Proyectos Destacados:

* 📦 **[SistemaInventario](https://github.com/Galucio-97/SistemaInventario-)**  
  Sistema web empresarial en **.NET 8 & ASP.NET Core** para administración y valuación dual de inventarios (PEPS vs Promedio Ponderado), kardex histórico, transacciones ACID, contenedores **Docker** y una suite exhaustiva de pruebas unitarias y de integración desarrolladas con metodología **TDD (xUnit)**.

* 🧺 **[TintoClean](https://github.com/Galucio-97/TintoClean)**  
  Sistema comercial de punto de venta (POS) y control de tintorerías en **Java 21** y **MySQL**. Implementa arquitectura por capas **MVC + DAO** y una interfaz moderna con el look-and-feel de **FlatLaf**.

* 🥗 **[Food-Planner](https://github.com/Galucio-97/Food-Planner)**  
  Aplicación móvil creada en **Flutter & Dart** para la organización de menús semanales, filtros reactivos de recetas y persistencia de datos local eficiente mediante shared_preferences.
